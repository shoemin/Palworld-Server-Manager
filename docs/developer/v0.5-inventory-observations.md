# Host inventory observations

`ServerInventoryRepository.Read(ServerRef)` reads one exact local, Host-qualified row from the existing authoritative SQLite inventory. A read-only connection and transaction observe the initialized Host, exactly one active Owner and inventory together. A missing row returns null; a missing database/root is an error and is never created. The reader makes no authoritative state writes.

The immutable result preserves the recorded name, nullable installation path, both Int32 ports, nullable import provenance and canonical UTC creation time. Empty and absent strings remain distinct. SQLite storage types are checked without permissive getters/coercion; malformed types, overflow or invalid timestamps produce a constant error without submitted values. Existing historical names and ports are not silently normalized, clamped or repaired. The result is a Host-only observation, not a wire DTO or diagnostic object; default object formatting does not print its fields. Host callers must never serialize raw inventory into logs or ordinary client responses.

The trusted Host caller retains machine exclusivity and separately enforces current authorization. An observation grants no capability, does not resolve or validate a filesystem path, and says nothing about process state. In particular, missing inventory or a null path is not proof that a prior process lifetime has finalized. Later lifecycle operations must validate their own inputs, establish protected managed paths, acquire operation locks and perform current permission/revision/recovery checks at the effect boundary. Settings saves must use that real lifecycle authority rather than a settings-only stopped flag.

This is a bounded #48 prerequisite for inventory/lifecycle and #47 target resolution. Create/import/delete, process tracking/reattachment, SteamCMD, auto-start and all RPCs remain unimplemented by this reader. No schema, creator grants, permissions, frozen WPF behavior or migration rules change. No physical Palworld or Windows parity result is claimed.
