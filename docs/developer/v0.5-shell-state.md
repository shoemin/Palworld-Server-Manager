# Avalonia shell state foundation

Trial reference: #52, bounded unit #52a. The shell model consumes the authenticated local Host's authorized inventory through `ReplaceAuthorizedInventory`. It does not discover servers, infer inventory from trust, or grant authority. No inventory RPC is introduced by this unit. Actual views, activation UI and visual/input qualification remain subsequent #52 units.

`ShellState` is owned by the UI thread. Each row, focus, selection and selector invocation retains the exact `ServerRef(AuthoritativeHostId, ServerProfileId)`. Display labels cannot redirect a target. Host aliases and server aliases are not reused during the model lifetime; shortened Host UUID suffixes expand on collisions. Full UUIDs are available in the accessible identity text. Control and Unicode format characters in labels are replaced so they cannot forge the identity layout.

Focus inspection does not select. Selection awaits the injected Host revalidation function; its response can commit only if it is still the current request and its target remains visible. Inventory replacement and scope changes invalidate pending requests. Denial, exception or cancellation of current revalidation clears that same selected target. An older reply cannot redirect or clear a newer selection. Disconnect clears inventory, focus and selection. None of these presentation checks replaces Host authorization on future operations.

`ShellTokens` embeds the accepted [#34 semantic token source](../design/astra-34/tokens.json). Refined, Dark Minimal and Light Minimal share dimensions, typography and spacing. Below 1200 units the rail is 88 units and the Activity drawer overlays; at larger widths the rail is 280 units and the drawer is 304 units. Reduce motion resolves feedback and panel durations to zero. This model does not claim that a view has applied those choices yet.

Ordinary self-tests exercise duplicate names, colliding Host UUID suffixes, repeated profile UUIDs across Hosts, stable aliases, atomic rejection of invalid inventory, focus/selection separation, stale/denied/failed/canceled selection, semantic contrast, responsive dimensions and reduced motion. The same model source and embedded tokens compile into the self-test assembly without adding an Avalonia-to-Host/Core reference. Rendered geometry, keyboard automation and actual accessibility/visual evidence are required later; these model tests are not substitutes.
