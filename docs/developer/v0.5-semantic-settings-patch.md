# Semantic settings patch preparation

Trial reference: #47. `PalworldSettingPatch.Prepare` is a pure Core operation over a [preserved byte snapshot](v0.5-preserved-settings-encoding.md). It validates and serializes explicit dirty edits using the accepted catalog and project-owned quotation rules. It does not write files, issue revisions, authorize a caller or declare a server stopped. A successful prepared result is only a proposed document.

An omitted setting or explicit `Unchanged` preserves its original bytes. Ordinary `Set` accepts only supported nonsecret semantic settings. Text is quoted with escaped quotes/backslashes; booleans use canonical True/False; valid integer, multiplier, duration and enum input retains its explicit representation. No game range, default or restart rule is invented. Unknown/future Raw and compound edits remain unsupported. Unselected future enum choices, unknown values, comments, whitespace, secrets and original encoding remain untouched.

Passwords require `ReplaceSecret` or `ClearSecret`. Empty replacement refuses and never silently clears a value; whitespace replacement is not trimmed. Explicit clear writes a quoted empty value. Unsupported controls or invalid Unicode cannot pass into the preserved-value writer; these are representation limits, not guessed password policy. Existing secrets are never copied into errors. Request/result classes are not records; replacement text is not a public property and is omitted by default JSON serialization. Errors contain only the request index and closed codes, optionally the catalog validation code. They never retain submitted keys or values. Do not log raw input buffers or prepared file contents.

All edits are validated before constructing the output. Any error returns no output and leaves the original unchanged. Case-alias duplicate requests and edits to duplicate source keys refuse; unrelated duplicate source keys remain preserved. No-op preparation returns the original immutable snapshot. Request bounds are 1,024 edits, 256-character identifiers matching the preserved parser, and 1,048,576 total key/value UTF16 code units; final document and encoding bounds still apply. Errors caused by final representation/size limits apply to the whole request (index -1).

Later Host code must verify actual installation/schema availability, exact server identity and current EditSettings permission, both remote ceilings, the authoritative increasing revision, stopped/finalized lifecycle state, durable operation locks and protected atomic replacement/recovery. ViewServer remains an independent permission for nonsecret reads. This component introduces no RPC or save request contract and does not complete #47.

Six test groups cover exact selected-byte changes, explicit secret actions and diagnostic redaction, whole-patch refusal, aliases/duplicate source/malformed/bounded requests, all six supported file encodings and 1,000 seeded quoted edits that cannot inject neighboring settings. An independent preparation probe and 10,000 quoted text/password pairs additionally verify roundtrips and unchanged source bytes. No Palworld execution, field parity, UI or release qualification is claimed.
